# COO Toolkit — Templates, Boilerplates, Frameworks and Spreadsheets

Thirty templates, one spreadsheet workbook. Every exercise in the course that says "fill T-something" lands here: each template is a copy-ready note — purpose, rules, the template itself, and a VSYST example where useful — and the numbers live in [vsyst-coo-workbook.xlsx](vsyst-coo-workbook.xlsx). The rule of the house: **these files are blank masters — copy them, never fill them in place.** Filled copies live in a `coo-workbook/` folder next to the course (the landing page's rule), and the workbook's working copy lives in Google Sheets. If a template doesn't fit VSYST, change the master — and note the change in the file so the next person inherits your version. The templates exist because of the course's law: _if it happens twice, write it down_ — each one is the written-down form of something every company does more than twice.

## The workbook — vsyst-coo-workbook.xlsx

[vsyst-coo-workbook.xlsx](vsyst-coo-workbook.xlsx) is the numbers half of the toolkit — one .xlsx, sixteen tabs, built to import into Google Sheets (below). Yellow cells are input, blue are formulas (don't overwrite), example rows are grey italic; **every tab has exactly one named owner** — shared ownership is no ownership.

1. **README** — how the workbook works: colour code, owners, the one-owner rule.
2. **Runway & 13-Week Cash** — cash, burn, runway and the week-by-week grid whose job is to expose the trough ([[T20-budget-vs-actual-and-cash-forecast|T20]]).
3. **Budget vs Actual** — monthly plan vs actuals with variance flags and one-sentence commentary (T20).
4. **KPI Scorecard** — the Monday numbers, 13 trailing weeks, RAG rules ([[T05-kpi-scorecard|T05]]).
5. **OKR Tracker** — the quarter's objectives and KRs with owner, confidence and score ([[T06-okr-planning-sheet|T06]]).
6. **Compliance Calendar** — statutory items, forms, typical dates, owner, status ([[T16-compliance-calendar|T16]]).
7. **Vendor & Tool Register** — every vendor and subscription: cost, renewal, criticality, exportability ([[T14-vendor-and-tool-register|T14]]).
8. **Risk Register** — scored risks with mitigations, early warnings and review dates ([[T15-risk-register|T15]]).
9. **RACI** — activities × roles, with the exactly-one-A check column ([[T07-raci-matrix|T07]]).
10. **Hiring Pipeline** — one row per candidate per role: stage, scores, next step ([[T10-hiring-scorecard-and-process|T10]]).
11. **Headcount Plan** — 18 months of roles with hiring triggers and loaded monthly cost ([[T21-headcount-plan|T21]]).
12. **Decision Log** — the log: doors, review dates, outcomes ([[T09-decision-log-and-adr|T09]]).
13. **Cadence Calendar** — every ritual with day, time, duration, owner and artefact ([[08-the-operating-cadence|lesson 08]]).
14. **SOP Index** — id, owner, status and review date of every SOP; the source of truth for the library ([[T08-sop-template|T08]]).
15. **DoA Matrix** — decision types × ₹ thresholds × who decides × who is informed ([[T22-delegation-of-authority-matrix|T22]]).
16. **Automation Backlog** — candidate automations: task, frequency, minutes, risk, tool, owner, status ([[18-automation-and-ai-in-operations|lesson 18]]).

## How to copy a template in Obsidian

A template is a note; copying it is the whole trick — the master stays blank.

- [ ] Open the template note; command palette (`Ctrl/Cmd-P`) → **"Make a copy of the current file"** (or right-click the file in the explorer → Make a copy).
- [ ] Move the copy into the `coo-workbook/` folder next to this course (create it once; that folder is live company records, not course material).
- [ ] Rename it for the instance: `T10 — Support-Ops Associate — 2026-09`, `T18 — Helpdesk rollout`.
- [ ] Delete the guidance sections in the copy if you like; the Template and Example sections are the working part.
- [ ] If the master itself was wrong for VSYST, fix the master too — and add a line at the bottom noting what changed and why.

## How to import the workbook into Google Sheets

Do this once; the Sheets copy becomes the working workbook and the vault's .xlsx stays the blank template.

- [ ] In Google Drive: **New → File upload** → select `vsyst-coo-workbook.xlsx` from the vault folder.
- [ ] Open the uploaded file → **File → Save as Google Sheets** (this converts it; the .xlsx original stays in Drive — archive or delete it to avoid two copies).
- [ ] Spot-check the conversion: tab count (16), the README colour key, one formula cell per tab (blue cells should still compute), date columns render as dates.
- [ ] Rename it `VSYST COO Workbook — live`, share view access with all directors and edit access per tab owner, and pin the link in the ops channel.
- [ ] Enter real data only in the Sheets copy. If a master tab's structure improves later, port the change by hand — don't re-import over live data.
