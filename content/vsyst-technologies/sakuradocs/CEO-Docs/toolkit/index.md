# CEO Toolkit — Templates, Frameworks and the Workbook

Thirty templates, one spreadsheet workbook. Every exercise in the course that says "fill C-something" lands here: each template is a copy-ready note — purpose, when to use it, opinionated rules, the template itself, and a worked VSYST example — and the numbers live in [vsyst-ceo-workbook.xlsx](vsyst-ceo-workbook.xlsx). The rule of the house: **these files are blank masters — copy them, never fill them in place.** Filled copies live in a `ceo-workbook/` folder next to the course; the workbook's working copy lives in Google Sheets. If a template doesn't fit VSYST, change the master — and note the change in the file so the next person inherits your reasoning, not just your conclusion.

Where the COO toolkit exists because _if it happens twice, write it down_, this one exists for a different reason: **a CEO's decisions are invisible unless they are written.** A strategy nobody can repeat back to you isn't one; a decision without its reasoning can't be reviewed in six months; a trigger agreed in the calm is the only kind that survives the panic. Each template below is one of those made durable.

## The workbook — vsyst-ceo-workbook.xlsx

[vsyst-ceo-workbook.xlsx](vsyst-ceo-workbook.xlsx) holds the numbers behind the templates: **14 tabs, live formulas, colour-coded** (pale yellow italic = illustrative example data to overwrite · pale blue = a computed cell, don't type over it · pale green = an input).

| Tab                    | What it does                                                               | Owner · cadence                  |
| ---------------------- | -------------------------------------------------------------------------- | -------------------------------- |
| `README`               | Tab guide, colour legend, import note                                      | CEO · on every version bump      |
| `Strategy Kernel`      | The kernel, the choice cascade, the assumption register, the review log    | CEO · quarterly                  |
| `Market Map`           | TAM/SAM/SOM off the per-GSTIN price, segment scores, penetration scenarios | CEO · half-yearly                |
| `Unit Economics`       | Cost to serve, CAC, payback, LTV, the default-alive count                  | CEO with CA · quarterly          |
| `Runway & Scenarios`   | Bear/base/bull drivers, 24-month projection, trigger ladder, exit reserve  | CEO · monthly                    |
| `Cap Table & Dilution` | Today's table plus a two-round model with the pre/post pool switch         | CEO with CS · on any change      |
| `ESOP Pool`            | Pool size, grant register with vesting maths, guidelines by level          | CEO with CS · on every grant     |
| `CEO Dashboard`        | ~18 monthly rows, cash and strategy first, RAG computed                    | CEO · monthly by the 5th         |
| `Annual Plan & OKRs`   | The year's bet, objectives, key results, typed confidence                  | CEO · annually, scored quarterly |
| `Decision Journal`     | Every decision worth remembering, with the quality-vs-outcome verdict      | CEO · at the decision            |
| `Board Calendar`       | Meeting dates with the statutory gap computed, and the filings you sign    | CEO with CS · set in April       |
| `Pipeline`             | The CEO's own named-dealer pipeline, weighted, with the blocking objection | CEO · after every call           |
| `Comp Bands`           | Bands by role and level, plus an offer check                               | CEO · annually                   |
| `Risk & Pre-Mortem`    | Causes of death scored, early-warning signals, crisis playbooks            | CEO · quarterly                  |

**The workbook follows the markdown, never the reverse.** If a figure disagrees between a template and a tab, the template wins — fix the tab. The file is generated by `_build_ceo_workbook.py`; change that script and re-run it rather than hand-editing the spreadsheet, or the two will drift.

## How to copy a template in Obsidian

1. Right-click the template note → **Make a copy**, or open it and `Ctrl/Cmd-A`, `Ctrl/Cmd-C` into a new note.
2. Put the copy in `ceo-workbook/` (create it next to `CEO-Docs/`), named for what it is and when: `C04-strategy-kernel-2026-Q3.md`.
3. Fill the copy. **Leave the master blank** so the next version starts clean.
4. If you improved the master while filling it, edit the master too — and say what you changed and why in the file.

## How to import the workbook into Google Sheets

1. In Google Drive: **New → File upload**, choose `vsyst-ceo-workbook.xlsx`.
2. Open it, then **File → Save as Google Sheets**.
3. Re-check the formulas on `Cap Table & Dilution`, `Runway & Scenarios` and `ESOP Pool` — those carry the most nested logic and are the ones worth spot-checking after any import.
4. Share it with the co-directors as editor, and keep the `.md` masters here as the reference.

## Which template in which phase

| Phase                       | Window      | Fill these                                                                                                                                                                                                                                     |
| --------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1 — Understand the Seat** | Week 0      | C01, C02, C03 — the charter and the founder contracts. Nothing else works until these are signed. Start C29 the same week, even with decisions already made.                                                                                   |
| **2 — The Outward Job**     | Months 1–3  | C04, C05, C06 (strategy) → C07, C08, C11, C12 (moat, positioning, price, unit economics) → C09, C10 (customers and the pipeline) → C13 (runway and the trigger ladder) → C17, C18 (the board). C14–C16 only if the raise trigger in C13 fires. |
| **3 — The Inward Job**      | Months 2–9  | C19, C20 (hiring and equity) · C21 (values) · C22, C23, C24 (comms) · C25 (product bets) · C26 (partnerships).                                                                                                                                 |
| **4 — Running the Company** | Months 6–24 | C27 (your week) · C28 (the annual plan) · C29 (kept continuously) · C30 (pre-mortem, crisis, succession — the bus-factor half is urgent and cheap; do it early).                                                                               |

If you only ever fill four: **C01** (the seat exists), **C04** (the direction is written), **C13** (you will not be surprised by cash), and **C29** (you will get better at deciding). Everything else compounds off those.
