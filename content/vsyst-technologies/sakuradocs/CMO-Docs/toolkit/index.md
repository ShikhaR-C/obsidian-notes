# CMO Toolkit — Templates, Scripts and the Workbook

Fourteen templates, one spreadsheet workbook. Every exercise that says "fill M-something" lands here: each template is a copy-ready note — purpose, when to use it, rules, the template, a worked VSYST example — and the numbers sit in [vsyst-cmo-workbook.xlsx](vsyst-cmo-workbook.xlsx). House rule: **these are blank masters — copy them, never fill them in place.**

The COO toolkit exists because _if it happens twice, write it down_; the CEO toolkit because a CEO's decisions are invisible unless written. This one exists for a third reason: **if you said it to one dealer, write it down so the next person says it the same way.** Three founders selling in three directions invent three companies unless the pitch, the objection answer and the referral ask are on paper. Scripts, named lists and counted numbers are what let marketing be repeated by someone other than the founder who invented it — the other two directors first, then a field associate, then a district you have never seen.

## The workbook

[vsyst-cmo-workbook.xlsx](vsyst-cmo-workbook.xlsx) is the numbers half — **eight tabs, live formulas**, colour-coded as in the CEO and COO workbooks: **pale green = an input you type · pale blue = a formula, leave it alone · pale yellow italic = an example row to overwrite.** One named owner per tab.

| Tab                   | Serves                                              | You type                                                   | Computed                                              |
| --------------------- | ----------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------- |
| `Target List`         | [[M03-target-list-builder\|M03]] with [[M02-icp-and-persona-field-cards\|M02]] · 03 | Pump, owner, place, distance, volume, source, route in    | ICP score, rank, count inside 60 km, % of ICP reached |
| `Pipeline`            | [[M07-sales-pipeline-tracker\|M07]] + [[M06-demo-flow-and-pilot-offer-sheet\|M06]] · 06 | Stage, last touch, next step **and** date, objection      | Days since touch, stage conversion, Week-12 forecast, stale flag |
| `Marketing Scorecard` | [[M13-marketing-scorecard-and-cac-calculator\|M13]] + [[M01-marketing-charter-and-90-day-plan\|M01]] · 11 | The eight HC8 actuals, every Monday                       | 13-week trend, goal vs red line, RAG colour           |
| `CAC & Payback`       | [[M13-marketing-scorecard-and-cac-calculator\|M13]] · 11 | Per channel per quarter: cash, founder hours, travel, **paying** dealers | Cost at the imputed rate, CAC, blended CAC, payback |
| `Campaign Budget`     | [[M12-campaign-brief-budget-and-post-mortem\|M12]] · 10 | Each line: ₹ planned, ₹ actual, owner                     | Variance, spend vs the monthly ceiling, cost per activation |

**The workbook follows the markdown, never the reverse.** If template and tab disagree, the template wins — fix the tab. Import it once into Google Sheets, share it with the co-directors; the `.md` masters stay the reference.

## In what order

| When           | Fill                              | The trigger                                                                                                       |
| -------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Week 0**     | M01                               | Nothing below is worth filling until one founder owns marketing and the hire question is closed.          |
| **Week 1**     | M02, M03, M04, M05                | The charter is signed. Before any forecourt: who, where, what we say, in whose words.                  |
| **Weeks 2–12** | M06, M07, M08, M09, M10, M12, M13 | The first field day is booked. M12 before a rupee is spent · M06 that morning · M07 that evening · M08 the day a dealer says yes. |
| **Months 3+**  | M11, M14                          | The visit motion repeats. M11 once content has proof to carry; M14 when all three HC1 triggers hold.   |

If you only ever fill four: **M03**, **M05**, **M08**, **M13** — whose door, one voice, both sides live, the cost.

## House rules for using templates

- **Copy, don't edit the master.** Right-click → **Make a copy**, name it for the instance (`M12 — Raipur 100 — 2026-Q4`), leave the blank one here. If the master was wrong, fix it and say why.
- **Filled copies are company records, not course material.** They live in a `cmo-workbook/` folder beside this course, or wherever live records go — ERPNext CRM once up, the shared Sheet until then. Never two copies of one list.
- **One owner per artefact — a person, not a seat.** Three owners is no owner; a row with no next action and no date is dead.
- **Hindi lines are spoken lines.** Say them aloud before you send them; one that reads well and sounds wrong is worse than none. The domain director's ear is final.
- **VERIFY LIVE every ₹ figure before it reaches a dealer** — prices, pilot terms, rewards, bands — against the signed-off sheet that day. A withdrawn number costs more trust than it bought.
