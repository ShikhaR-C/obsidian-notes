## ट्यूटोरियल

हाथों-हाथ अभ्यास, **चरणों (phases)** में बँटा हुआ और क्रमांकित **steps** के साथ। कीबोर्ड पर साथ-साथ करें।

| #   | ट्यूटोरियल                                          | समय              | क्या अभ्यास होगा                                                                                                                     |
| --- | --------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 11  | [आपका पहला TDD फ़ीचर](11-tutorial-first-feature-hi.md) | 45–60 मिनट       | 8 चरणों में शून्य से एक signup फ़ीचर बनाएँ — चक्र, triangulation, test doubles, outside-in, commit की लय।                            |
| 12  | [अभ्यास katas](12-tutorial-katas-hi.md)                | हर एक 15–60 मिनट | पाँच क्रमबद्ध katas (FizzBuzz → Bowling), हर एक चरणों में, साथ में विशेष कौशल के लिए बंदिशें।                                        |
| 13  | [अपनाने के चरण](13-adoption-phases-hi.md)              | ~3 महीने         | क्रमबद्ध रोडमैप: तैयारी → प्रवाह → बग फ़िक्स → नया कोड → पुराना कोड → टीम → निरंतरता। हर चरण में एक **मिनी-प्रोजेक्ट** और ठोस नतीजा। |

## पूरी बात एक वाक्य में

> बनाने से _पहले_ लिख लें कि आपको कैसे पता चलेगा कि यह काम करता है — फिर उतना ही बनाएँ जितने से वह बात सच हो जाए।

## चक्र (The loop)

```
   ┌─────────────────────────────────────────┐
   │                                         │
   ▼                                         │
🔴 RED          →     🟢 GREEN     →    🔵 REFACTOR
फेल होता टेस्ट        पास कराएँ           सफ़ाई करें
लिखें                (सबसे आसान तरीक़े से)  (टेस्ट पास रहें)
```

चक्र का हर फेरा **मिनटों में पूरा होना चाहिए, घंटों में नहीं**। अगर एक फेरे में पूरी दोपहर लग रही है, तो आपका कदम बहुत बड़ा था।
