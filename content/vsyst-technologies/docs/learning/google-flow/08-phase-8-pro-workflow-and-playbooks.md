# Phase 8 — The Professional Workflow & Content Playbooks

> Level: Capstone | Time: ongoing | Outcome: you run the whole stack as one assembly line, and you have copy-paste playbooks for the five things we actually make — marketing films, ads, promos, tutorials, and images. | Status: written & web-verified 2026-07-15; **tool facts re-verified and corrected 2026-10-01**.

## 1. The One Idea

A professional doesn't "make a video." They run an **assembly line** where each station does one job and hands off to the next. You've now learned every station. This phase bolts them together and gives you a recipe card for each kind of thing DZZLO needs to ship.

The line, end to end:

```
①  BRIEF        one line: what, who, where it plays              (Phase 3)
②  PLAN         Content Director Gem → script, shots, prompts    (Phase 7)
③  STILLS       Nano Banana in Flow → ingredients + start stills (Phase 5)
④  DRAFT ⏣      Flow Lite → does each shot work?                 (Phase 1)
⑤  ITERATE ⏣    Flow Fast → tune camera, timing, voice           (Phases 4,6)
⑥  LOCK ⏣⏣      Fast; Quality from a start still for heroes      (Phase 1)
⑦  ASSEMBLE     Vids → cut, captions, music bed, CTA card
⑧  QC           the checklist (§4) → brand, sync, sound, legal
⑨  SHIP         1080p upscale (0 coins) → export → Shorts / site / ad manager
⑩  ARCHIVE      Drive + winning prompt back into Brand Brain     (Phase 7)
```

Every station is cheap except ⑥. That's the design: all the thinking happens where it's free, and coins are spent only on the sure thing.

Station ⑦ is **Google Vids**, now a scene-based editor; it can't detach a clip's own sound, grade or change speed, so a dialogue-heavy story film goes to DaVinci Resolve (free edition) — [[17-editing-1-workflow-and-the-cut]] §2.

## 2. The Assembly Rule: Batch, Don't Trickle

The efficiency multiplier isn't per-clip — it's **per-batch.** Once you're set up, run a whole content week in one sitting:

```
Monday plan:  1 brief → Gem → 6 shots across 3 assets
              → 1 Nano Banana session makes every ingredient + start still
              → 1 Flow session drafts all 6 on Lite (~60 coins)
              → tighten 6 on Fast (~120), lock 6 on Quality (~600)
              → 1 Vids session assembles all 3 assets
Total: ~780 coins → 3 finished pieces of content in one day.
```

That ~780 is the ceiling — every shot locked at Quality; most can keep their Fast take. Trickling one clip at a time re-pays every setup cost each time. Batching amortises it. A content calendar in Sheets (one row per asset, columns for brief/status/coins) is what turns this from "making videos" into "running a content factory."

## 3. The Five Playbooks

Each is a recipe: **format · shot skeleton · camera · audio · budget · assembly.** Adapt, don't worship. Each video budget is the ceiling — every shot locked at Quality; most can keep their Fast take.

### 3.1 Marketing / Brand Film

*Goal: make people feel something about DZZLO. Emotion over features.*

| Field       | Recipe                                                                    |
| ----------- | ------------------------------------------------------------------------- |
| Format      | 16:9 or 9:16, 20–40 s (3–5 shots, joined by cuts)                         |
| Shots       | Aspiration → struggle → transformation → brand promise                    |
| Camera      | Cinematic: aerial opener, handheld human moments, low-angle hero, crane-up close |
| Audio       | Emotional music bed (Google Flow Music), light ambience, one line of VO at the end |
| Consistency | One character (Ravi) in every shot's start still (Quality takes no Ingredients); locked palette |
| Budget      | ~4 Lite + 4 Fast + 4 Quality ≈ **520 coins**                              |
| Assemble    | Vids: shots + Flow Music bed + logo end-card                               |

### 3.2 Advertisement (Product Ad)

*Goal: sell a specific thing. Clear, fast, one CTA.*

| Field       | Recipe                                                                    |
| ----------- | ------------------------------------------------------------------------- |
| Format      | 9:16, 10–15 s (2 shots) — hook in <2 s or they scroll                     |
| Shots       | Hook (problem/pattern-break) → product-solves-it + CTA                     |
| Camera      | Product **orbit/push-in**, shallow DoF, 35mm; spokesperson eye-level      |
| Audio       | Snappy music, one SFX on the product reveal, ≤12-word CTA line            |
| Consistency | Product pinned in every shot (**ingredient**, or start still for Quality); logo visible |
| Budget      | ~4 Lite + 3 Fast + 2 Quality ≈ **300 coins**                              |
| Assemble    | Vids: 2 shots + captions + CTA card + music                                |

### 3.3 Promotion (Offer / Sale / Launch)

*Goal: drive urgency around a specific deal or new feature.*

| Field       | Recipe                                                                    |
| ----------- | ------------------------------------------------------------------------- |
| Format      | 9:16, 8–15 s — often a **single strong shot** + text overlay              |
| Shots       | One attention-grabbing beat; the *offer* carried by on-screen text        |
| Camera      | Energetic: quick push-in or zoom; bright, high-key                        |
| Audio       | Upbeat, a chime/whoosh on the offer reveal; spoken offer line optional    |
| Consistency | Brand palette + logo; reuse an existing ingredient or still to save coins |
| Budget      | ~2 Lite + 1 Fast + 1 Quality ≈ **140 coins** — the cheapest format        |
| Assemble    | Vids text overlay for the offer ("30% off — this week only")               |

> Promos are where you spend the *least* per piece and post the *most* often. Reuse ingredients, stills and winning prompts ruthlessly; the novelty is in the offer text, not a new shoot.

### 3.4 Tutorial / How-To Video

*Goal: teach a feature. Clarity over flash. This is the most **Vids-heavy** playbook.*

The insight: a tutorial is mostly **real screen-recording** of DZZLO, with Veo used for the **human bookends** — a friendly intro and outro presenter — and Nano Banana for **callout graphics.** You don't animate the whole app in Veo; you record the real thing.

| Field       | Recipe                                                                            |
| ----------- | --------------------------------------------------------------------------------- |
| Format      | 16:9, 30–90 s; structured as intro → steps → recap → CTA                          |
| Veo shots   | 1 presenter intro ("Here's how to add a driver") + 1 outro CTA — that's it        |
| Real assets | **Screen-record** the actual DZZLO flow (Loom/OS recorder); crop to the UI        |
| Graphics    | Nano Banana (in Flow) for arrows, highlight callouts, step numbers                |
| Audio       | Presenter's own Veo line, or a locked voice ([[06-phase-6-voice-lipsync-audio]] §4); soft bed |
| Consistency | Same presenter (ingredient or start still) on every tutorial → a recognisable "DZZLO teacher" |
| Budget      | ~2 Lite + 2 Fast + 2 Quality ≈ **260 coins** (only the 2 human shots cost Veo)    |
| Assemble    | **Vids** does the heavy lifting: presenter + screen-rec + callouts + captions      |

> Tutorials are the best coins-to-value ratio you have: the expensive part (the actual product footage) is *free* screen-recording, and Veo only pays for two short human shots. Make a **series** with one consistent presenter and you build a whole help-centre cheaply.

### 3.5 Images (Static Creatives)

*Goal: ad creatives, thumbnails, social posts, banners. **Few or no coins.***

| Field       | Recipe                                                                    |
| ----------- | ------------------------------------------------------------------------- |
| Tool        | **Nano Banana** in Flow (Pro, 2 or 2 Lite) — from text, or remix subject + scene + style images |
| Uses        | Ad images, YouTube thumbnails, carousel posts, hero banners, App-store shots |
| Consistency | Same subject/style ingredients as your video → images *match* the films   |
| Text-on-image | Add headlines in Vids/any editor — don't rely on the model for crisp text |
| Budget      | Stills are cheap — Nano Banana 2 Lite is free; check the cost Flow shows for the other image models |
| Bonus       | Every good image doubles as a **storyboard frame** or **Frames→Video** start |

> On Nano Banana 2 Lite, images cost nothing, so generate **generously** there: a batch of 20 variations to find the one hero creative is free — the opposite of video, where every render counts. For a hero that needs several references, finish on Pro or 2 — check the cost Flow shows first.

## 4. The Pre-Publish QC Checklist

Run this before anything ships — a few minutes here saves a re-shoot (full technical pass: [[20-colour-finishing-and-delivery]] §11):

- [ ] **Brand voice** — sounds like DZZLO, not generic AI?
- [ ] **Character consistency** — same face/product/logo across all shots?
- [ ] **Palette** — brand colours present and correct?
- [ ] **Lip-sync** — mouth matches words on every dialogue shot, every Hinglish word right?
- [ ] **Audio levels** — VO clear over the music bed? About −14 LUFS integrated, peaks ≤ −1 dBTP (a practitioner target — no platform publishes an official number), checked on a phone ([[19-sound-edit-design-and-mix]] §10)?
- [ ] **Captions** — no *unwanted* burned-in subtitles; wanted captions correct — burned in or an .srt, never both ([[20-colour-finishing-and-delivery]] §8.4, §10)?
- [ ] **Aspect ratio** — right shape for the platform (9:16 vs 16:9), vertical delivered at 1080 × 1920?
- [ ] **Safe zone** — every caption, logo and CTA inside x 65–888, y 288–1248 of the 1080 × 1920 frame ([[20-colour-finishing-and-delivery]] §9)?
- [ ] **Hook** — does something happen in the first 2 seconds?
- [ ] **CTA** — is the next action unmistakable?
- [ ] **Claims** — every factual/product claim is *true* and matches the Brand Brain?
- [ ] **Rights** — no real person's likeness/voice faked; music terms read and filed (rights aren't disclosure)?
- [ ] **AI disclosure** — every platform's AI question answered honestly (YouTube "AI use", Meta's "AI info" label, India's upload declaration — law since 20 Feb 2026); never an AI "testimonial" ([[20-colour-finishing-and-delivery]] §12)?
- [ ] **Watermark** — Flow's visible mark (applied automatically for people living in India) and invisible SynthID intact — never cropped, covered or blurred ([[20-colour-finishing-and-delivery]] §2.3)?
- [ ] **Archived** — clip + prompt saved to Drive; winner fed back to the Brain?

## 5. The Weekly Cadence (running it for real)

| Day        | Station                                                        |
| ---------- | ------------------------------------------------------------- |
| **Mon**    | Briefs → Content Director Gem → plans for the week's assets    |
| **Tue**    | Nano Banana in Flow: all ingredients + start stills, one session |
| **Wed**    | Flow: draft (Lite) → iterate (Fast) the whole batch           |
| **Thu**    | Flow: lock approved shots (Fast, or Quality from a still); Vids assembly |
| **Fri**    | QC, schedule/publish, archive, feed winners to the Brain      |

One person, one stack, a week of consistent DZZLO content — inside AI Pro's jar (**about 1,000 coins a month, plus 50 a day; neither rolls over**) if you obeyed the Prime Directive all along. Spend each day's 50 on drafts ([[21-long-form-multi-scene-production]] §7).

## 6. Capstone Exercises

**6.1 — Ship one real ad (budget ≤300 coins).** Full line, §1 ①–⑩, using the 3.2 playbook. Brief → Gem → stills → Lite → Fast → Quality (from a still) → Vids → QC → export. Post it or file it. This is the whole course in one afternoon.

**6.2 — Build a tutorial series pilot (≤260 coins).** Using 3.4: one screen-recording of a real DZZLO flow, Veo presenter bookends with your consistent "teacher," Nano Banana callouts, assembled in Vids. If it works, you've got a repeatable help-centre format.

**6.3 — Fill a content calendar.** In Sheets: 8 assets across the five types for one month. Assign each a playbook, a coin budget, and a status column. Total the coins — does the month fit AI Pro's jar (1,000 a month, plus 50 per day you generate)? Rebalance until it does (hint: more promos/images, fewer brand films).

**6.4 — Batch a promo trio (≤300 coins).** Three §3.3 promos in one session, all reusing the *same* ingredients or stills and one music bed, differing only in the offer text — share the shot itself where you can (three new §3.3 shots at ~140 each would be ~420). Feel how batching + reuse drops the per-piece cost through the floor.
