# Roadmap — Phases & Sub-Phases with Doable Tasks

**Purpose:** synthesize all strategy notes into a single phased execution plan. Every task here is a concrete, owner-assignable action. Use this as the operating document; revisit weekly.

---

## Executive summary

| Phase | Months | Gate | Headcount | ARR | Raise |
|---|---|---|---|---|---|
| **Phase 0 — Bootstrap PMF** | 0–6 | 50 paying dealers, 85% retention | 8 | ₹2–5L MRR | None (grant) |
| **Phase 1 — Seed** | 6–14 | 100 dealers, 3-state | 12 | ₹30–50L ARR | ₹2–4 Cr |
| **Phase 2 — Series A** | 14–24 | 300 dealers, fintech live | 25 | ₹3–5 Cr ARR | ₹15–30 Cr |
| **Phase 3 — Series B** | 24–36 | 1,000+ dealers, 2 corridors | 60 | ₹15–25 Cr ARR | ₹60–100 Cr |

Each phase has 2–3 sub-phases. Each sub-phase has a gate — you don't begin the next sub-phase until the gate is passed.

## Decision points to revisit at each phase gate

- **Pricing:** still right? (re-run Van Westendorp on fresh sample)
- **Positioning:** still differentiated? (competitive landscape scan)
- **Team composition:** right shape for next phase?
- **Channels:** current channel still scaling, or hit saturation?
- **Product:** Digital-Lite still standard? Power Mode uptake growing?
- **Unit economics:** NRR, GRR, CAC payback still on track?
- **Regulatory:** any new forcing functions (e.g., dispenser verification Jan 2026 ruling outcome)?

Add these questions to the agenda at every phase-gate meeting with the board.

## Red-team quarterly review

Every quarter, pick one of these to pressure-test:

- "If our biggest competitor took ₹10 Cr tomorrow, where would they strike?"
- "If an OMC built their own DZZLO clone, what's our moat 12 months out?"
- "If EV adoption doubles next year, which modules die?"
- "If two co-founders lost alignment, what's the continuity plan?"
- "If WhatsApp API pricing doubled, what's our channel backup?"

Write the answer; file it with the board minutes.
