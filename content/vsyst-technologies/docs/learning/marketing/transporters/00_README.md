## How citations work

Every factual claim is followed by a link like:

```
[a16z](99_References.md#a16z-fintech-scales-vsaas)
```

Clicking it jumps to the source card in `99_References.md`, which has the URL, author, purpose, and list of notes that cite it.

`99_References.md` is organised into 13 Parts (A–M) grouped by topic:

- **A–F** — Vertical SaaS, compound playbook, canonical companies, Indian VSaaS, fuel-retail ecosystem
- **G** — Marketing fundamentals (4Ps/7Ps, STP, funnels, AARRR, positioning, messaging)
- **H** — SaaS sales, GTM, qualification frameworks
- **I** — Pricing and packaging
- **J** — Indian SMB, Bharat, WhatsApp
- **K** — Regulatory, policy, payments rails
- **L** — Transporter / fleet / fuel competitive ecosystem
- **M** — EV / biofuel / long-term energy transition
