## Recommended Reading Order

For someone new to India's CBDC:
1. Start with the **RBI Concept Note** (Oct 2022) — the definitive foundation document
2. Read **this documentation** (files 01 through 10)
3. Check the **Atlantic Council CBDC Tracker** for latest global context
4. Visit **RBI's latest press releases** for most current updates
5. Compare with **BIS mBridge** documentation for cross-border perspective
