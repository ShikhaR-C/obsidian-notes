# Blockchain Learning Path

A 20-file, newbie-to-builder learning series covering everything from "what is a blockchain" to "how do I integrate it into a production SaaS." Every file is self-contained but designed to read in order.

## Where to Start

If you are new to blockchain and want the single best entry point, start with **`17-newbie-guide.md`**. It is the "if you only read one file" file — a complete guided tour from zero knowledge to a 4-week self-study plan. From there, follow the suggested reading order below based on your goals.

If you already know the basics and just want a specific topic, jump straight to that file. Each file begins with a "What you'll learn" summary so you can decide quickly.

## Notes

- Every file is designed to be read independently if you already know the basics.
- Every topic file starts with a "What you'll learn" summary and ends with a "Next file to read" pointer.
- Glossary entries for any unfamiliar term can be found in `20-blockchain-glossary.md`.
- Code examples in tutorials assume you have Node.js and a modern browser. Specific dependencies are listed in each tutorial.
- This series aims to be honest and balanced, not hype-y. If a use case has a bad track record, we say so. If a claim is contested, we say so.
